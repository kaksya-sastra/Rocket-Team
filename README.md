# Rocket-Team
NACDec-X and InSpace:

Student-led rocket design, simulation,
development and testing project.
## Technical Subteams
1. Avionics
2. Trajectory
3. Propulsion
4. Structural
5. Parachute and Recovery

## Repository Structure
- avionics/
- trajectory/
- propulsion/
- structural/
- recovery/
- integration/
- docs/
- data/
- media/

## Team Workflow
1. Each subteam works in its respective folder.
2. All significant changes must be committed.
3. Experimental changes should use branches.
4. Important changes require a Pull Request.
5. Main branch contains reviewed project work.

## Documentation Rules
- Include units in engineering data.
- Record assumptions in calculations.
- Include software/tool versions.
- Document simulation conditions.
- Maintain revision history.

## Project Status

Currently in preliminary design phase.
